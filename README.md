# Pickleball Scorer

A lightweight pickleball scoring app built with plain HTML, CSS, and JavaScript.

## Features

- Singles and doubles scoring modes
- Serving team, server number, and court-side tracking
- Undo and reset controls
- Customizable team names
- Optional voice callouts with a TV-broadcast style
- Mobile-friendly layout for courtside use

## Run locally

This is a static app, so you can open `index.html` directly in a browser.

## Project files

- `index.html` - app structure
- `styles.css` - responsive styling
- `app.js` - scoring logic and voice announcements
